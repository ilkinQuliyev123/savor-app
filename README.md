# Savor — Restaurant Mobile App

A restaurant ordering app built with **React Native (Expo), TypeScript and NativeWind (Tailwind CSS)**.

**Features:** menu by category, dish details, cart, order placement with live status tracking (Preparing → On the way → Delivered), table reservations.

> Demo project: menu items are fictional, data lives in memory.

## Run

```bash
npm install
npx expo start      # press a (Android), i (iOS) or w (web)
```
